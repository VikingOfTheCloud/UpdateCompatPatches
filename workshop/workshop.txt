description=[h2]Compatibility patches for Project Zomboid updates[/h2]
description=When a game update lands, some mods stop loading or break until their authors catch up. This mod bridges that gap without touching any other mod's files: everything is applied in memory while the game loads, and each rule only switches on when the game really needs it.

description=[h3]What it does[/h3]
description=[list]
description=[*][b]Version unlock.[/b] A mod whose mod.info says versionMax 42.21 is skipped by 42.22, even if nothing else changed. Listed mods are allowed to load on games up to the version in the rule. On the next game update the rule stops applying, so nothing loads blind.
description=[*][b]Class adapter.[/b] 42.22 removed or moved some game code that Java mods call (PZArrayList, the rope and ladder climb states, IsoPlayer.isHeavyItem). When a mod's class loads, its calls to that code are pointed at the new game code. A rule only switches on when the old code is really gone from the running game.
description=[*][b]Admin menus out of the Viewpoint picker.[/b] In Viewpoint's first- and third-person view, other mods' admin and debug menus (Companion Dogs (debug), RC Structures, Barrels Expanded's Admin / Debug, LG Extended Plumbing, Better Building Plus's BBP Admin and Free Place) are removed from the action picker. The classic view keeps them, and players without admin rights never see those menus anyway.
description=[*][b]Immersive Snow - Viewpoint on Viewpoint 0.1.6.2.[/b] The add-on only accepts Viewpoint 0.1.6 and 0.1.6.1, so on 0.1.6.2 it takes Immersive Snow's snow out of the 3D view and shows a "not supported" message. This turns off the add-on's Viewpoint version check, only for Viewpoint 0.1.6.2 with bridge 1.3, so people can use it until its author updates. Nothing else is changed. [b]Use at your own risk:[/b] the add-on's author hasn't tested this Viewpoint version and I don't support it. I may fix simple problems in this patch, but no promises. If you report a problem to the add-on's author, mention this patch was on.
description=[/list]

description=[list]

description=[*]3D Construction ladder animations: the ladder hooks target climb states that 42.22 removed; ladders use the game's own climbing
description=[*]Third-person hooks in some add-ons that look for Viewpoint's old third-person class
description=[/list]
description=
description=[h3]Known issue: one extra mod reload when joining[/h3]
description=If you keep the server's mod list switched on in your main menu, the game drops the four unlocked mods (3D Construction, 3D Doors, Rolling Hills, Visceral) from that list at every launch: it checks mod versions at startup, before ZombieBuddy loads this patch. When you join, the server's list adds them back and the game reloads all mods once. Nothing breaks; the join just takes longer. This comes from the order the game runs its checks in, so this patch won't get a fix for it. It goes away for each mod once its author updates it for 42.22.
description=

description=[h3]Multiplayer[/h3]
description=Add it to the server's WorkshopItems= and Mods= so every player gets it. Its Java only runs on players; a server does not run it. A dedicated server applies the same version check to its own copies of each mod, so a server that should load an out-of-date mod also needs that mod's versionMax raised in the server's own copy of its mod.info.
